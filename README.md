# 🌍 M2 SISE 2025 – Projet Python / Machine Learning  
## **GreenTech Solutions – Enedis DPE App**

### 📘 À propos du projet
Ce projet a été réalisé dans le cadre du Master 2 SISE (2025-2026).  
L’objectif est de développer une **application web interactive** permettant aux particuliers d’**évaluer le Diagnostic de Performance Énergétique (DPE)** d’un logement et d’**estimer la consommation énergétique associée**.

Ce projet s’inscrit dans un contexte de **sobriété énergétique** et de **transition écologique**, en partenariat avec **Enedis** et **GreenTech Solutions** (entreprise fictive).

---

### 🎯 Objectifs
- Analyser l’impact de la **classe DPE** sur les **consommations électriques** des logements.  
- Construire des **modèles de Machine Learning** pour prédire :
  - la **classe DPE** (modèle de classification),
  - la **consommation énergétique** (modèle de régression).
- Développer une **application web interactive (Dash/Shiny)** pour visualiser les données et effectuer des prédictions.
- Déployer l’application sur le web (Render, Shiny, ou Heroku).
